# Enterprise Network Design

A **self-directed networking project** developed using **Cisco Packet Tracer** to practice enterprise network design and CCNA networking concepts.

## Implemented

* Hierarchical network design
* VLSM subnetting
* VLANs
* Access & trunk ports
* Port Security
* IP addressing

## Planned

* OSPF
* DHCP
* Wireless
* NAT/PAT
* ACLs
* HSRP / VRRP
* Additional network security
* Network services
* Testing & troubleshooting

## Status

**In Progress — Self-Directed Learning Project**
